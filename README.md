## Hi there, I'm João Pedro Mota (@Mistertelecom) 👋

I'm an **ISP Network Engineer** and **Software Developer** focused on building robust network automation tooling, managing core infrastructure, and contributing to leading open-source projects in the AI space. 

Based in Brazil 🇧🇷, I work daily with large-scale network architecture bridging legacy systems with modern software defined flows. When I'm not configuring BGP or OLT GPON networks, I'm writing code for Open Source projects that empower AI engineering and developer tools.

### 🛠 Tech & Infrastructure
- **Languages:** Python, TypeScript, C#, Bash
- **Networking:** OLT GPON (VSOL, Parks, FiberHome, Huawei), MikroTik (RouterOS), Cisco
- **Protocols & Routing:** BGP, CGNAT, L2TP, WireGuard VPNs, VLAN bridging
- **Software Engineering:** Multi-agent Systems, AI Gateway Integrations, Automation Tooling, Containerization/Docker
